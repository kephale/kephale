# Kyle I S Harrington

I'm a machine learning and computer scientist working on biological image analysis, interactive visualization, and scientific software. I build open-source tools for exploring large datasets and turning computational methods into useful research workflows.

[Website](https://kyleharrington.com) · [Repositories](https://github.com/kephale?tab=repositories)

## Selected projects

| Project | What it does |
| --- | --- |
| [Lodstone](https://github.com/kephale/lodstone) | Renderer-neutral, view-dependent streaming of multiscale arrays, with integrations for scientific viewers. |
| [CellCanvas](https://github.com/cellcanvas) | Tools for interactive annotation, machine learning, and exploration of cellular architecture. |
| [copick](https://github.com/copick/copick) | Collaborative annotation and data management for cryo-electron tomography. |
| [SciView](https://github.com/scenerygraphics/sciview) | Interactive visualization of multidimensional images, meshes, and other scientific data. |
| [rstar-python](https://github.com/kephale/rstar-python) | Python bindings for dynamic spatial indexing with Rust's rstar library. |

I also contribute to [napari](https://github.com/napari/napari), [VisPy](https://github.com/vispy/vispy), [ndv](https://github.com/pyapp-kit/ndv), and [SceneX](https://github.com/pyapp-kit/scenex).

For other projects, the linked repositories are the best place for questions, reproducible bug reports, examples, and contribution proposals.
